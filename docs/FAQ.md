# FAQ

**Is this a hacking toolkit?**  
यह defensive learning, system diagnostics और authorized testing platform है. Unauthorized access इसका उद्देश्य नहीं है.

**Can I use it on an unrooted Android phone?**  
Yes. Termux works within Android's app sandbox. Some diagnostics require ADB from a separate computer.

**Does it unlock phones or bypass FRP/MDM?**  
No. Use manufacturer-supported account recovery and repair channels.

**Are all tools available on Android?**  
No. Tool support depends on Android version, CPU architecture, permissions, and dependencies.

**Can I run every command with sudo?**  
No. These scripts are designed for ordinary user privileges. Never run an unknown script as root.

**Are logs safe to publish?**  
Not automatically. Logs can contain personal or security-sensitive data; redact them first.
