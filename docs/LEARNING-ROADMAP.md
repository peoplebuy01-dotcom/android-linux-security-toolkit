# Beginner to Advanced Learning Roadmap

## Stage 1 — Terminal foundations
Learn paths, files, pipes, help pages, environment variables, and safe permissions. Practice only inside a temporary learning directory.

## Stage 2 — Android administration
Understand Developer Options, ADB authorization, device properties, storage, battery diagnostics, and log privacy. Use your own phone or emulator.

## Stage 3 — Linux operations
Learn processes, services, system logs, package managers, users, storage, and networking. Know which commands are read-only and which alter state.

## Stage 4 — Networking and TLS
Study IP, DNS, TCP, HTTP, certificates, and packet metadata using sample captures and your own local test services.

## Stage 5 — Application security
Inspect an intentionally vulnerable training APK. Review manifest permissions, exported components, storage choices, and TLS configuration. Document fixes.

## Stage 6 — Advanced authorized lab
Use MobSF, JADX, Apktool, Ghidra, Frida, and proxy tools only in isolated, explicitly authorized environments. Build a report with evidence, impact, and remediation.

## Portfolio outcome

Create a sanitized lab report, a small defensive script, and a clear explanation of the security lesson. Never publish real user data, credentials, or proprietary app code.
