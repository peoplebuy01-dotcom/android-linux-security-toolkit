## How to use this collection responsibly

1. Open the original repository and read its README.
2. Open its current LICENSE file before reusing any code.
3. Check the project's maintenance status, security policy, releases, and open issues.
4. For learning, clone or fork the original repository while preserving attribution.
5. Do not upload copies of other authors' code as if you created it.

## Verification method and limitations

The repository names were gathered from GitHub repository search sorted by stars and filtered with GitHub's recognized license identifiers: `mit`, `apache-2.0`, `gpl-3.0`, `bsd-3-clause`, and `mpl-2.0`. The original GitHub links are the upstream owner/repository paths. GitHub search results and license classifiers can change; this file is a snapshot, not a legal certification. Re-check the upstream LICENSE before every reuse.

**No upstream repository has been copied into this project.** This file is only a curated directory with links and license-filter labels.
