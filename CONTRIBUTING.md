# Contributing

Thanks for helping improve this bilingual learning project.

1. Open an issue describing the correction or proposed lab.
2. Keep examples reproducible and scoped to owned/authorized systems.
3. Prefer read-only commands and non-destructive defaults.
4. Use clear Hindi + English explanations where practical.
5. Test shell scripts with `bash -n scripts/name.sh`.
6. Do not add secrets, private logs, unverified binaries, malware, bypasses, or exploit instructions for real targets.
7. Explain platform/version assumptions and risk levels.

By submitting a contribution, you agree that it may be distributed under this repository's MIT license.
