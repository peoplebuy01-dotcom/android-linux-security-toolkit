# Security Policy

## Scope

This project accepts reports about vulnerabilities in its documentation, scripts, or repository configuration.

## Reporting

Please do not publish secrets, personal data, or an unpatched vulnerability in a public issue. Contact the repository maintainer through the private security reporting feature on GitHub.

Include affected file/version, impact, safe reproduction steps, and suggested mitigation. Do not access or alter third-party systems during research.

## Project safety

Scripts are intended to be read-only diagnostics. Review before execution. Never run untrusted content with elevated privileges. The project does not support unauthorized unlocking, FRP/MDM bypass, credential theft, covert surveillance, malware deployment, persistence, or evasion.
