# Code of Conduct

We are committed to a welcoming, respectful learning community.

Expected behavior: be respectful, constructive, patient with beginners, and considerate across languages and experience levels.

Unacceptable behavior: harassment, threats, discrimination, doxxing, publishing private information, malicious code, or encouraging unauthorized access.

Project maintainers may edit or remove content that violates these standards. For concerns, contact the repository maintainer privately through GitHub.
